# Wayfarer ✈️

Perfil de viagens responsivo desenvolvido com HTML e CSS como desafio prático da Rocketseat.

## 🛠️ Tecnologias

- HTML5
- CSS3
- Flexbox e Grid
- Media Queries
- Mobile First

## 🚀 Objetivo

Praticar a criação de layouts responsivos, adaptando a interface para dispositivos móveis, tablets e desktops.
